## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/rahul-kapgate/My-Protfolio.git
```

### 2. Navigate to the project

```bash
cd My-Protfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```

---

## Build for Production

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
